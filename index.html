Sakirea プライバシーポリシー

最終更新日：2026年11月7日

本プライバシーポリシーは、誕生日・プレゼント管理アプリ「Sakirea」 （以下「本アプリ」）におけるユーザー情報および端末情報の取扱いを説明するものです。

1. 端末内で管理する情報

本アプリは、ユーザーが登録した以下の情報を端末内で管理します。

  • 人物名
  • 誕生日・年代に関する情報
  • 性別等の任意プロフィール情報
  • 人物写真
  • 趣味・関心
  • 好み
  • 欲しいもの・気になっているもの
  • メモ
  • プレゼント履歴・候補
  • 通知設定

これらの正本は、端末内のSQLiteおよびアプリ専用領域に保存します。 人物データのクラウド同期は行いません。

Androidのクラウドバックアップ対象からは本アプリのデータを除外しています。 一方、ユーザーがAndroidの端末移行機能を利用した場合は、 OSの端末間転送機能により、データベースおよびアプリ管理下の人物写真が 新しい端末へ移行される場合があります。

人物写真は、ユーザーが端末から選択または撮影した画像をアプリ専用領域へコピーして管理し、 AIサービスや商品検索サービスへ送信しません。

2. AI相談で送信する情報

ユーザーがAIによるプレゼント提案を実行した場合、 提案に必要な範囲で以下の情報を本アプリのバックエンドへ送信します。

  • 年代
  • 趣味・関心
  • 好み
  • 欲しいもの・気になっているもの
  • プレゼント予算
  • 避けたいもの
  • ユーザーが今回入力した自由記述
  • 過去のプレゼント履歴の一部

AI相談では、人物名、人物写真、正確な誕生日、生年、性別を送信しません。 バックエンドはAI相談の入力本文を独自データベースへ永続保存せず、 通常のアプリケーションログにも入力原文を記録しません。

AI提案の生成にはOpenAI APIを利用します。バックエンドではResponses APIを store=false で呼び出します。OpenAI APIへ送信された入出力は、 OpenAIの標準設定ではモデルの学習・改善には利用されません。 ただし、標準の不正利用監視ログとして、入力・出力等が最大30日間保持される場合があります。

3. 商品検索で送信する情報

ユーザーが商品検索を実行した場合、以下の検索条件を本アプリのバックエンドへ送信します。

  • 検索キーワード
  • 価格条件
  • ページ番号等の検索条件

商品検索にはRakuten Web Serviceを利用するため、検索結果の取得に必要な範囲で 検索条件が楽天側へ送信されます。バックエンドは商品検索キーワードを 独自データベースへ永続保存せず、通常のアプリケーションログにも 検索キーワードや楽天からの生レスポンスを記録しません。

現在、楽天Affiliate機能は媒体登録完了前のため無効化しています。 将来、所定の媒体登録を完了して楽天Affiliateを有効化する場合は、 公開時点の条件とデータ取扱いを再確認し、必要に応じて本ポリシーを更新します。

ユーザーが商品ページを開いた後の楽天側での情報の取扱いは、 楽天グループが定めるプライバシーポリシーその他の適用条件に従います。

4. アプリの正当性確認と不正利用防止

本アプリはバックエンドの不正利用防止のため、Firebase App Checkおよび Google Play Integrityを利用します。これらのサービスでは、 アプリや端末の正当性を確認するため、Firebase Installation ID、アプリ情報、 端末情報、integrity token、ライセンス状態等の技術情報が処理される場合があります。

これらの情報は、本アプリおよびバックエンドの保護、不正利用防止、 セキュリティ、サービス運用のために利用します。

5. バックエンドの運用ログおよび診断情報

本アプリのバックエンドでは、安定運用、セキュリティ、不正利用防止、 レート制限、障害調査のため、以下のような運用上の情報を処理する場合があります。

  • リクエスト日時
  • APIのパス
  • ステータスコード
  • 処理時間
  • 利用した外部サービスの種別
  • エラー種別
  • IPアドレス、User-Agent等のネットワーク・リクエスト情報
  • サーバーログに含まれる技術情報

Google Cloud Runではリクエストログが自動生成されます。 本アプリでは、これらの運用情報を位置情報の推定や広告プロフィール作成のためには利用しません。

レート制限用のFirestoreには、処理対象の種別、時間枠、集計回数、有効期限等の 集計メタデータだけを保存し、人物データ、AI入力本文、商品検索キーワード、 App Check tokenは保存しません。

6. 利用目的

  • AIによるプレゼント提案
  • 商品検索
  • アプリ・端末の正当性確認
  • 不正利用防止
  • レート制限
  • セキュリティ
  • 障害調査およびサービスの安定運用

現在の本アプリでは、広告配信、広告プロフィール作成、 広告計測を目的としたユーザーデータの収集は行いません。 また、専用のAnalytics SDKやCrashlyticsは導入していません。

7. 外部サービス

本アプリでは、主に以下の外部サービスを利用します。

  • Google Cloud / Firebase
  • Google Play Integrity
  • OpenAI API
  • Rakuten Web Service

各サービスへ送信された情報は、各サービス提供者の利用規約、 プライバシーポリシー、データ処理条件等に基づいて処理されます。 各サービスのインフラ構成により、日本国外で情報が処理される場合があります。

8. 情報の保存期間と削除

人物プロフィール、写真、プレゼント履歴等の端末内データは、 ユーザーが本アプリ内で対象人物を削除した場合、 関連する端末内データおよびアプリ管理下の人物写真を削除します。

本アプリをアンインストールした場合も、通常は端末上の本アプリ専用データが削除されます。 ただし、アンインストール前にAndroidの端末移行機能で別端末へデータを移行している場合は、 移行先端末のデータは別途削除する必要があります。

本アプリにはユーザーアカウント機能はありません。 バックエンドは人物プロフィールのクラウド上の正本を保持せず、 AI入力本文および商品検索キーワードを独自データベースへ永続保存しません。

レート制限用の集計メタデータには自動的な有効期限を設定します。 バックエンドの運用ログはGoogle Cloudのログ保存設定に従って一定期間保持されます。 本アプリ独自の長期保存用データベースへ運用ログを転記しません。

外部サービス側における保存期間は、各サービス提供者の最新ポリシーや契約条件に従います。 OpenAI APIでは、標準の不正利用監視ログが最大30日間保持される場合があります。

プライバシーに関するお問い合わせは下記の連絡先で受け付けます。 ただし、本アプリにはユーザーアカウントやメールアドレスとバックエンド上の運用情報を 直接紐づける仕組みがないため、問い合わせメールを一律のデータ削除申請窓口としては扱いません。

9. セキュリティ

  • 本番環境との通信にHTTPSを使用します。
  • Firebase App Check / Google Play Integrityでバックエンドを保護します。
  • 外部サービスの認証情報をモバイルアプリへ埋め込まず、Secret Managerで管理します。
  • Secret、token、AI入力原文、商品検索キーワードを通常のアプリケーションログへ出力しません。
  • バックエンドで人物データの永続的なマスターレコードを作成しません。

10. Androidの権限

Android版では、主に以下の権限・機能を利用します。

  • インターネット接続
  • 通知
  • 端末再起動後の通知再設定

現在のAndroid Manifestでは、位置情報、連絡先、マイク、 広範囲のストレージアクセス等の権限は宣言していません。

人物写真の選択等については、AndroidのシステムPicker等を利用し、 不要な広範囲ストレージアクセスを要求しません。

11. 本ポリシーの変更

アプリ機能、外部サービス、SDK、データフロー、法令またはプラットフォームポリシーが 変更された場合、必要に応じて本ポリシーを更新します。 重要な変更を行う場合は、アプリ内表示、公開ページの更新その他の適切な方法でユーザーへ周知します。
