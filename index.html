Vesplaria プライバシーポリシー

最終更新日：2026年11月1日

本プライバシーポリシーは、Vesplariaが提供する誕生日・プレゼント管理アプリ 「Vesplaria」（以下「本アプリ」）における情報の取扱いを説明するものです。

1. 本アプリが端末内で扱う情報

本アプリは、ユーザーが登録した以下の情報を端末内で管理します。

  • 人物名
  • 誕生日・年代に関する情報
  • 性別等の任意プロフィール情報
  • 人物写真
  • 趣味・関心
  • 好み
  • 欲しいもの・気になっているもの
  • メモ
  • プレゼント履歴・候補
  • 通知設定

現在のMVPでは、これらの正本を端末内のSQLiteおよびアプリ専用領域に保存し、 人物データのクラウド同期は行いません。人物写真は端末から選択または撮影された画像を アプリ専用領域へコピーして管理し、AIサービスや商品検索サービスへ送信しません。

2. AI相談で送信する情報

ユーザーがAIによるプレゼント提案を実行した場合、提案に必要な範囲で以下の情報を 本アプリのバックエンドへ送信することがあります。

  • 年代
  • 趣味・関心
  • 好み
  • 欲しいもの・気になっているもの
  • プレゼント予算
  • 避けたいもの
  • ユーザーが今回入力した自由記述
  • 過去のプレゼント履歴の一部

AI相談では、人物名、人物写真、正確な誕生日、生年、性別は送信しません。 バックエンドはAI相談の入力本文を独自のデータベースへ永続保存せず、 通常のアプリケーションログにも入力原文を記録しません。

AI提案の生成にはOpenAI APIを利用します。バックエンドではResponses APIを store=false で呼び出します。OpenAI APIに送信された入出力は、 OpenAIの標準設定ではモデル学習には利用されません。ただし、不正利用監視等の目的で 一定期間保持される場合があります。

3. 商品検索で送信する情報

ユーザーが商品検索を実行した場合、以下の検索条件をバックエンドへ送信します。

  • 検索キーワード
  • 価格条件
  • ページ番号等の検索条件

商品検索にはRakuten Web Serviceを利用するため、検索結果取得に必要な範囲で 検索条件が楽天側へ送信されます。バックエンドは商品検索キーワードを独自DBへ 永続保存せず、通常のアプリケーションログにも検索キーワードやProviderの 生レスポンスを記録しません。

4. アプリの正当性確認と不正利用防止

本アプリはバックエンドの不正利用防止のため、Firebase App Checkおよび Google Play Integrityを利用します。これらのサービスでは、 Firebase Installation ID、アプリ情報、端末情報、integrity token、 ライセンス状態等の技術情報が処理される場合があります。

5. バックエンドの運用情報

安定運用、セキュリティ、不正利用防止、レート制限のため、リクエスト日時、 APIパス、ステータスコード、処理時間、Provider種別、エラー種別、 ネットワークやサーバーログに含まれる技術情報を処理する場合があります。

レート制限用Firestoreには、処理対象の種別、時間枠、集計回数、有効期限等だけを保存し、 人物データ、AI入力本文、商品検索キーワード、App Check tokenは保存しません。

6. 利用目的

  • AIによるプレゼント提案
  • 商品検索
  • アプリ・端末の正当性確認
  • 不正利用防止
  • レート制限
  • セキュリティ
  • 障害調査およびサービスの安定運用

現在のMVPでは、広告配信、広告プロフィール作成、本格的なAnalyticsのために ユーザーデータを収集しません。

7. 外部サービス

現在のMVPでは、主に以下の外部サービスを利用します。

  • Google Cloud / Firebase
  • Google Play Integrity
  • OpenAI API
  • Rakuten Web Service / Rakuten Affiliate

各サービスへ送信された情報は、各Providerの利用規約、プライバシーポリシー、 データ処理条件等に基づいて処理されます。また、Providerのインフラ構成により、 日本国外で情報が処理される場合があります。

8. 情報の保存期間と削除

人物プロフィール、写真、プレゼント履歴等のローカルデータは、 ユーザーが本アプリ内で対象人物を削除した場合、関連するローカルデータと アプリ管理下の写真を削除します。

本アプリのバックエンドは人物プロフィールのクラウド上の正本を保持せず、 AI入力本文および商品検索キーワードを独自DBへ永続保存しません。 レート制限用の集計メタデータには自動的な有効期限を設定します。 外部Providerにおける保存期間は各Providerの最新ポリシーに従います。

9. セキュリティ

  • 本番通信にHTTPSを使用します。
  • Firebase App Check / Play Integrityでバックエンドを保護します。
  • Providerの認証情報をモバイルアプリへ埋め込まず、Secret Managerで管理します。
  • Secret、token、AI入力原文、商品検索キーワードを通常ログへ出力しません。
  • バックエンドで人物データの永続的なマスターレコードを作成しません。

10. Android権限

Android版では、主に以下の権限・機能を利用します。

  • インターネット接続
  • 通知
  • 端末再起動後の通知再設定

人物写真の選択等については、可能な範囲でAndroidのシステムPickerを利用し、 不要な広範囲ストレージアクセスを要求しません。

11. 本ポリシーの変更

アプリ機能、外部Provider、SDK、データフロー、法令またはプラットフォームポリシーが 変更された場合、必要に応じて本ポリシーを更新します。重要な変更を行う場合は、 適切な方法でユーザーへ周知します。
